# 硬件选型与要求

## 零、总原则：什么样的随身 WiFi 能接进来

**跟型号无关，取决于两件事**：

| 条件 | 说明 | 没有会怎样 |
|---|---|---|
| **① 有可编程的管理接口** | HTTP 后台 / ADB / SSH / 串口 —— 至少有一个能拿数据、能执行命令 | 只能当普通热点用，界面里啥都看不到 |
| **② 能开高级权限** | 网络 ADB、root、或**支持装插件/扩展** | 只能看状态，不能执行命令 |

**只要这两条满足，原则上任何随身 WiFi 都能接进来** —— 只需要给它写一个"通道"（见 [开发指南](开发指南.md)）。

---

## 一、可接入的三类设备

### A 类 · 带插件/扩展能力的（接口最全）★ 推荐

典型代表就是 **中兴 U30 Air + UFI-TOOLS**。这类设备的后台往往提供：

- REST 接口（电量、流量、信号、存储、温度、连接设备列表）
- **执行命令的接口**（U30 上就是 `POST /api/root_shell`，直接给 root 权限）
- 有的还能装插件、跑脚本

**能拿到的东西最多**：不只是状态，是**完整的命令执行能力**。本项目对这类设备的支持最完整（面板 + Root 终端 + 文件管理）。

### B 类 · 能装 App 的 Android 随身 WiFi

- 通过 **ADB** 接入
- 能装自己的 App/助手进去，App 再暴露本地 HTTP 接口
- 能力次之：终端、文件管理没问题，但**拿不到厂家内部的深度数据**（流量统计、基带信号等）

### C 类 · 只能开 ADB 的普通随身 WiFi

- 通过 **网络 ADB** 接入
- **能用**：终端、文件管理、安装/卸载、跑命令
- **缺**：面板（电量/流量/信号）需要自己解析，很多型号拿不到

> 很多"随身 WiFi 刷了 Android"的机型属于这类，也完全可用，只是功能少一截。

## 二、兼容性自查清单

拿到一台随身 WiFi，按这个顺序确认：

### 第 1 步 · 后台有没有可编程接口

```
① 浏览器打开后台，看地址栏端口
   常见：80 / 8080 / 2333（UFI-TOOLS）

② 按 F12 → Network，操作一下页面（刷新状态、看流量）
   - 能看到 JSON 响应 → **有 API**，记下路径和请求头 → A 类，可以深度接入
   - 全是服务端渲染的 HTML → 只能靠 ADB → B/C 类

③ 看请求头有没有签名
   - 有（如 kano-sign）→ 说明接口是对外开放的，可以照抄算法接入
   - 只是 Cookie 会话 → 也能用，但要注意会话过期
```

### 第 2 步 · 能不能开 ADB

```
设置里找："ADB 调试" / "网络调试" / "开发者选项" / "USB 调试"

开好后在电脑上试：
  adb connect <设备IP>:5555
  adb shell id
```

- 连上且返回 `uid=2000(shell)` → 可以接入（B/C 类）
- 提示需要授权，而设备上没弹窗 → 这台设备基本没法用（本项目在车机上踩过这个坑）

### 第 3 步 · 有没有 root / 高级权限

```
adb shell su -c id
```

- 返回 `uid=0` → 最好，什么都能做
- Permission denied → 看还有没有"插件/扩展"功能；都没有就只能做基础功能

### 第 4 步 · 能不能装插件或应用

后台里找："插件" / "扩展" / "应用市场" / "脚本"。
**有 = 上限很高**（可以自己写个插件把数据吐出来）。

## 三、参考型号：中兴 U30 Air（本项目验证过的）

### 为什么它是"标准答案"

因为它 A 类特征最全：**有 REST 接口 + 有命令执行接口**。本项目对它做了最完整的支持：

| 能力 | 依赖 |
|---|---|
| 面板（电量/流量/信号/存储/温度） | UFI-TOOLS 的 REST 接口 |
| **Root 命令台** | `POST /api/root_shell`（后台自带） |
| 终端 / 文件管理 | 设备的**网络 ADB** |
| 令牌需求检查 | `/api/is_weak_token` 之类（部分固件没有） |

### 实测参数

| 项 | 值 |
|---|---|
| 后台固件 | UFI-TOOLS **3.8.0** |
| 后台端口 | **2333** |
| 系统 | Android **13** |
| 网络 ADB | `10.126.126.1:5555` |
| 默认后台密码 | `admin` |

### 后台接口鉴权（逆向所得，接别的 UFI-TOOLS 设备同样适用）

请求需要三个头：

```
authorization = sha256hex(后台密码)                        # 默认 admin
kano-t        = 任意数字串
kano-sign     = HmacSignature(secret, "minikano" + METHOD + path + timestamp)
```

`HmacSignature` 不是标准 HMAC，是这套后台自己的算法：

```
1. h = HMAC-MD5(secret, msg)
2. 把 h 对半切成 a、b
3. A = sha256hex(a);  B = sha256hex(b)
4. 结果 = sha256hex(A + B)              # 拼接后再 sha256
```

- secret = `minikano_kOyXz0Ciz4V7wR0IeKmJFYFQ20jd`
- timestamp = 当前毫秒时间戳（程序自动生成）

**拿到会话后**，`POST /api/root_shell` 带上命令，返回的就是 **root 权限**的执行结果。

> 别的 UFI-TOOLS 设备：先用第 2 节的"自查清单"确认端口和路径，通常只需要改 `electron/channels/ufi.js` 里的路径和签名。

### ⚠️ 红线（务必遵守，与型号无关）

- **不要换卡**：很多"无限流量"卡是**机卡绑定**，换卡会锁卡
- **不要换设备**：把卡插到别的设备同样可能触发锁卡
- **不要刷机 / OTA**：可能丢接口、丢保修
- 本项目内置"红线守卫"，**严格模式下这些操作被硬禁用**（防误触）

## 四、其它两台设备

### C3（comma three）

| 项 | 要求 |
|---|---|
| 系统 | AGNOS（实测 12.8 / 内核 4.9.103 aarch64） |
| openpilot | 官方 / SunnyPilot / FrogPilot / CarrotPilot… |
| SSH | 已开启，**推荐密钥**登录 |
| 权限 | 有免密 `sudo` |
| 投屏额外要求 | `/data/openpilot` 可写 + 系统有 gcc（用来编译钩子） |

**投屏原理**：用一个 `LD_PRELOAD` 钩子挂进 openpilot 的 **ui 进程**，在 `eglSwapBuffers` 里 `glReadPixels` 读自己的帧缓冲（RGB24 写到 `/dev/shm/ui.rgb`）。**在 GL 上下文内部读，格式天生线性** —— 这正是不怕显卡压缩格式的原因（从进程外读 DRM 扫描输出会得到 UBWC 压缩的雪花）。

### BYD DiLink 车机

| 项 | 要求 |
|---|---|
| 车型 | BYD DiLink 3.0（实测 Android 10） |
| 网络 ADB | 开发者选项打开，实测 `192.168.0.100:5555` |
| root | **不需要**（抓屏用 `screencap`，操作用 `input tap`） |

摄像头实时取流当前不可行，见 [车机摄像头调查](车机摄像头调查.md)。

### 电脑

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 **x64** |
| 权限 | 首次启动同意一次 **UAC**（创建虚拟网卡） |
| 依赖 | **无需安装** Node / Python / adb（都内置） |

### 网络拓扑

```
        ┌────────────┐        ┌──────────────┐
        │  你的电脑   │        │  EasyTier    │
        │ Windows    │◄──────►│  公共服务器   │
        └─────┬──────┘        └──────┬───────┘
              │                      │
              │   虚拟网段 10.126.126.0/24
        ┌─────▼──────┐   ┌───────────▼────────┐   ┌──────────────┐
        │ 随身 WiFi   │   │   C3 (comma three) │   │  BYD 车机     │
        └────────────┘   └────────────────────┘   └──────────────┘
```

三台设备**不需要在同一局域网**：EasyTier 组进同一个虚拟网段，程序再走各自的 HTTP / SSH / ADB。
