# 部署流程

从零到能用的完整流程。全程大约 **15 分钟**。

---

## 阶段 0 · 准备（10 分钟）

### U30 Air

1. 插卡、开机、确认能上网
2. **打开网络 ADB**：设置里找「ADB 调试 / 网络调试」打开
3. 记下**后台密码**（未改过就是 `admin`）
4. 记下它的 IP（连上后网关一般就是，或在后台看）

### C3 (comma three)

1. 开机、联网、确认能 SSH
2. 准备好登录方式：
   - **密钥**（推荐）：把私钥放到电脑上，比如 `C:\Users\你\.ssh\c3_id_ed25519`
   - 或密码
3. 确认 `sudo` 免密可用（AGNOS 默认可以）

### BYD 车机

1. 设置 → 关于 → 连点版本号，进**开发者选项**
2. 打开 **USB 调试**（网络调试）
3. 记下车机 IP（实测 `192.168.0.100`）

### 电脑

- 能上网
- 知道要放的目录（建议英文路径，中文也行）

---

## 阶段 1 · 解压运行（2 分钟）

```
远程控制台-v0.8.10-win64.zip
  └─ 远程控制台-win32-x64/    ← 解压到任意目录
       └─ 远程控制台.exe       ← 双击
```

**首次启动**：

1. 弹 **UAC** → 点「是」（要创建虚拟网卡）
2. 程序自动拉起 **EasyTier 内核**（窗口是隐藏的，别找）
3. 隧道起来后，顶栏「总览」的**隧道卡片**会变绿

> 内置了 `adb/` 和 `c3-keys/`，程序启动时会**自动接管** adb 路径和 C3 私钥路径 —— 换电脑、换路径都不用改设置。

---

## 阶段 2 · 配置设备（首次 5 分钟）

点顶栏「**设置**」，逐个确认：

### 1. adb 路径

**通常不用改**（包内自带）。如果你想用自己那份，改这里。

### 2. 三台设备的地址

| 设备 | 默认地址 | 说明 |
|---|---|---|
| U30 Air | `10.126.126.1`，后台端口 `2333`，ADB `5555` | 走隧道访问 |
| C3 | SSH `comma@192.168.0.66` + 密钥路径 | 走隧道访问 |
| 车机 | ADB `192.168.0.100:5555` | 走隧道访问 |

> 隧道起来后，这些 IP 会通过 EasyTier 转发，**不需要你和设备在同一个 WiFi**。

### 3. 后台密码

U30 的后台密码填对，否则面板和 Root 台拿不到数据。

---

## 阶段 3 · 验证（3 分钟）

### 一键巡检

顶栏「**总览**」→ 点「**一键巡检**」，应该看到 8 项全通过：

```
本机 adb 可用          ok    Android Debug Bridge version ...
EasyTier 隧道           ok    12 ms
局域网 192.168.0.0/24   ok    177 ms
U30 Air 后台 (:2333)    ok    UFI-TOOLS 3.8.0
U30 Air ADB             ok    device
C3 SSH                  ok    SSH 登录成功
车机 ADB                ok    device
红线守卫                ok    严格模式：恢复出厂/OTA 已硬禁用
```

**有红的怎么办**：

| 现象 | 处理 |
|---|---|
| 隧道 不通 | 看 `~/.remote-console/easytier.log`；点顶栏「隧道」→ 重启隧道（会再弹一次 UAC） |
| U30 后台 401/403 | 后台密码填错了 |
| U30 ADB offline | 点「重连 ADB」；还不行去 U30 上关一下再开 ADB |
| C3 SSH 失败 | 密钥路径/密码不对；或 C3 没联网 |
| 车机 ADB offline | 点「重连 ADB」；还不行在车机上**关一下再打开 USB 调试**（授权状态坏了时不弹框，只能这样或重启车机） |

## 阶段 4 · 用起来

### 日常最常用的三个

**① C3 投屏（可触控）**
```
点 C3 卡片「面板」→「投屏（可触控）」→「开始投屏」
画面出来后：鼠标点画面 = 点 C3，按住拖 = 滑动
想看摄像头原画：来源切「摄像头原画」
```

**② C3 参数**
```
点 C3 卡片「面板」→「参数」
左边分组标签点一下 → 右边列出该组参数
改值：直接在右侧输入框改 → 点「保存」
保险做法：改之前先「保存快照」，出问题对比差异改回来
```

**③ 车机投屏（可操作车机）**
```
点车机卡片「面板」→「投屏（车机画面）」→「开始投屏」
想看 360 全景：用车上实体键/挡位叫出全景，镜像里就能看到并直接点机位
```

### 出问题先看运行日志

侧栏「**运行日志**」→ 勾「只看错误/警告」。**所有未捕获异常（含堆栈）都在这里**，比截图管用。

## 阶段 5 · 进阶（可选）

### 让 C3 投屏开机就能用

投屏插件装在 C3 上（`/data/openpilot/.dsh/uihook.so`），**跟电脑无关**。首次点「安装插件」装好后，以后换电脑直接就能投。

### 命令库 / 脚本库

- **命令库**：常用命令存下来，按设备分组，一键执行或复制
- **脚本库**：脚本以真实 `.sh` 文件保存，可以关联设备、导入导出

### 主题与动效

顶栏「主题」切换 7 套配色；「设置」里可以关掉粒子动效（老机器或嫌费电）。

## 排错速查

| 症状 | 先看哪里 |
|---|---|
| 界面白屏 | 底部红色横幅会写原因 → 点「打开运行日志」 |
| 打不开 / 双击没反应 | 是不是已经开着（单实例锁）；任务管理器里关掉再开 |
| 隧道起不来 | `%APPDATA%\远程控制台\logs\app-*.log` + `~/.remote-console/easytier.log` |
| 某个面板一直"读取中" | 大概率是那台设备网络慢/掉线，看运行日志 |
| 投屏黑屏 | 面板上的「插件「徽章是不是"已加载"；没加载点「安装插件」 |
