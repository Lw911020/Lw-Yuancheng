面向要改代码 / 加设备 / 加功能的人。

## 一、三分钟跑起来

```bash
npm install
npm start            # 开发模式（Electron 直接加载源码，改完刷新即可）
```

**调试**：

```bash
# 带远程调试端口启动（可以用 CDP 驱动界面、截图）
electron . --remote-debugging-port=9222

# 打开 DevTools
set RC_DEVTOOLS=1 && npm start
```

> ⚠️ 开发时如果开着正式版程序，会因为**单实例锁**导致调试实例直接退出 —— 先关掉正式版。

| 文件 | 负责 |

## 三、加一台新设备（完整例子）

假设你有一台**别的品牌的随身 WiFi**，它有个 HTTP 后台能查状态、能执行命令。

### 1. 在配置里加目标

`electron/config.js`：

```js
targets: [
  // ...
  {
    id: 'mifi2', name: '某品牌随身 WiFi', kind: 'ufi', color: '#f59e0b', enabled: true,
    note: 'HTTP 后台',
    ufi: { base: 'http://10.126.126.3:80', password: 'admin' },
    adb: { addr: '10.126.126.3:5555' }
  }
]
```

### 2. 写通道（如果要新的协议）

参考 `electron/channels/ufi.js` 的结构：**导出纯异步函数，第一个参数通常是配置里的设备对象**。

```js
// electron/channels/mifi2.js
'use strict';
const http = require('http');

function api(target, path, method) {
  return new Promise((resolve, reject) => {
    const req = http.request({ host: ..., path: path, method: method || 'GET',
      headers: { /* 你的鉴权头 */ } }, (res) => {
      let b = '';
      res.on('data', (d) => { b += d; });
      res.on('end', () => {
        try { resolve(JSON.parse(b)); } catch (e) { resolve(b); }
      });
    });
    req.on('error', reject);
    req.end();
  });
}

module.exports = { api };
```

### 3. 在 main.js 里挂 IPC

```js
ipcMain.handle('mifi2:info', async () => {
  const t = cfg().targets.find((x) => x.id === 'mifi2');
  return mifi2.api(t, '/api/status');
});
```

### 4. 在 preload.js 里暴露给界面

```js
mifi2Info: () => ipcRenderer.invoke('mifi2:info'),
```

### 5. 写面板

`renderer/panels.js` 里加一个：

```js
PANELS.mifi2 = function (pane) {
  const box = el('div', 'panel');
  pane.appendChild(box);
  h2(box, '某品牌面板', '一句话说明');
  const cards = el('div', 'cards');
  box.appendChild(cards);
  async function load() {
    const d = await rc.mifi2Info();
    cards.innerHTML = '';
    cards.appendChild(card('电量', d.battery + '%', ''));
  }
  load();
  pane.refresh = load;              // 挂上 refresh，切标签时自动刷新
};
```

### 6. 加入导航

`renderer/app.js`：

- 侧栏：`tool('某品牌', function () { openPanel('mifi2', '某品牌'); })`
- 设备卡：`add('面板', ...)` / `add('终端', ...)`

**完成。** 不需要动其它任何地方。

## 四、加一个新面板（通用约定）

```js
PANELS.名字 = function (pane) {
  const box = el('div', 'panel');       // 面板容器（有统一样式）
  pane.appendChild(box);
  h2(box, '标题', '一句说明（可省）');   // 标题 + 小字说明

  const r = row();                       // 工具栏
  r.appendChild(btn('刷新', load, 'primary'));   // 每个面板最多一个绿色主按钮
  box.appendChild(r);

  const cards = el('div', 'cards');      // 卡片区
  box.appendChild(cards);
  const out = el('div', 'out');          // 日志/原始输出区
  box.appendChild(out);

  async function load() { /* 拉数据 → 填 cards */ }
  load();
  pane.refresh = load;                   // 必须挂，否则切回来不刷新
};
```

### 可用的工具函数（都在 `panels.js` 顶部）

| 函数 | 作用 |
|---|---|
| `el(tag, cls, text)` | 建元素 |
| `btn(label, fn, cls)` | 建按钮（`cls` 可为 `primary` / `small` / `danger`） |
| `h2(box, 标题, 说明)` | 面板标题区 |
| `row()` | 工具栏行 |
| `card(k, v, s)` | 卡片（标题/主值/说明） |
| `formModal(标题, 字段, 保存回调)` | 表单弹窗 |
| `A.modal(标题, 内容函数, 确认回调, 按钮文字)` | 自定义弹窗 |
| `A.toast(msg, 'fail')` | 提示 |
| `A.describeErr(e)` | 把异常转成人话 |

### 视觉约定（C 版打磨后定的）

- **一个面板最多一个绿色主按钮**（`primary`），其余中性灰
- 圆角：卡片 12px / 按钮 8px / 列表项 10px / 徽章全圆
- 层级：标题亮白加粗 13px → 主值 21px 加粗 → 说明 12px 淡（opacity .62）
- 状态色：`--accent`（在线）· 红（离线）· 橙（待确认）
- 按钮加图标（用符号字形，不引图片）：↻刷新 ⌨终端 ▤文件 ▣面板 ▶投屏 ⚙参数 ☰日志

## 五、打包与发布

```bash
# 打包（产物在 app/远程控制台-win32-x64/）
node recon/pack.mjs app
```

打包脚本会自动：

1. **语法闸**：扫描 `renderer/` 和 `electron/` 下所有 js，语法不过**直接拒绝打包**
2. 复制 `vendor/easytier/`（内核）→ `easytier/`
3. 复制 `vendor/c3/`（设备侧脚本）→ `c3/`
4. 复制 `pc-tools/platform-tools/adb.exe` + dll → `adb/`
5. 复制 `~/.ssh/c3_id_ed25519` → `c3-keys/`

> ⚠️ **第 5 步会把你自己的私钥打进包里**。发给别人前记得换成不含私钥的版本。

### 一键重建（关旧程序 → 清理 → 打包 → 启动）

```powershell
powershell -File recon/rebuild.ps1
```

### 发布

```bash
# 打包成 zip（用系统 tar，比 Compress-Archive 快很多）
cd app && tar -a -c -f ../远程控制台-vX.Y.Z-win64.zip 远程控制台-win32-x64
```

## 六、日志与排错

### 日志在哪

| 日志 | 路径 |
|---|---|
| 程序日志（含未捕获异常堆栈） | `%APPDATA%\远程控制台\logs\app-YYYY-MM-DD.log` |
| 隧道内核日志 | `~/.remote-console/easytier.log` |

### 主进程写日志

```js
const LOG = require('./log');
LOG.info('tag', '正常信息');
LOG.error('tag', '出错信息', err);      // 第二个参数后是 Error 对象时会带上堆栈
```

### 渲染进程写日志

```js
rc.logWrite('error', '详细信息');        // 会落到同一个文件，tag 是 renderer
```

**全局兜底已经做好了**：`uncaughtException` / `unhandledRejection`（主进程）、`window.onerror` / `unhandledrejection`（渲染进程）都会自动落盘，并且界面底部会弹**崩溃横幅**。

### 用 CDP 驱动界面（自动化验证）

```js
const ts = await (await fetch('http://127.0.0.1:9222/json')).json();
const ws = new WebSocket(ts.find(t => t.type === 'page').webSocketDebuggerUrl);
// 然后发 Runtime.evaluate / Page.captureScreenshot
```

## 八、代码约定

| 约定 | 说明 |
|---|---|
| **不用框架** | 渲染层是原生 JS + DOM，没有 React/Vue。改起来快，启动快 |
| **IPC 命名** | `模块:动作`，如 `cast:start`、`c3:params`、`log:tail` |
| **通道导出** | 纯异步函数，第一个参数是设备配置对象 |
| **错误处理** | 通道抛异常 → main.js 的 IPC 会把它转成 `Error invoking remote method`；界面用 `A.describeErr()` 显示 |
| **变量命名** | 别用会遮蔽外层作用域的名字（踩过坑：局部 `stream` 遮蔽了模块级的连接变量，导致主进程崩溃） |
| **提交前** | 至少跑 `node --check` 所有 js（打包脚本会自动做） |

## 九、常见坑（都是踩过的）

| 坑 | 表现 | 解法 |
|---|---|---|
| PowerShell 写 `.ps1` 不带 BOM | 中文路径变乱码，脚本语法错 | 写文件时加 `\ufeff` |
| PowerShell 的 `>` 重定向二进制 | PNG 被改坏打不开 | 用 `cmd /c "adb ... > file"` |
| PowerShell 读 UTF-8 文件 | 中文显示乱码 | 读的时候指定 `-Encoding UTF8`（文件本身没问题） |
| `adb root` | **会破坏设备授权状态**，只能重启设备恢复 | 别随便试 |
| 变量遮蔽 | 主进程崩溃（`Assignment to constant variable`） | 局部变量别跟模块级重名 |
| 程序运行时覆盖打包目录 | `EBUSY: resource busy or locked` | 先关程序（`recon/rebuild.ps1` 会处理） |
| Electron 带 `ELECTRON_RUN_AS_NODE` | `require('electron')` 拿不到 | 启动前清掉这个环境变量 |
