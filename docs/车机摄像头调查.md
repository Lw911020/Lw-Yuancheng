# 车机（BYD DiLink 3.0）摄像头取流：调查结论

**结论：当前权限状态下拿不到实时摄像头数据。** 不是路径缺失 —— 硬件和服务都在，卡在权限。

调查时间：2026-10-11 · 设备：DiLink3.0 For BYD AUTO (Android 10)

---

## 二、为什么三条路都走不通

### 1. `service call` 拿不到帧 —— 它是"注册 + 回调"模型

反编译 `BydCameraManager.apk` 得到 `com.byd.cameramanager.BYDCamMgrService`：

```
registerUser(IBYDCameraUser):Z          注册（带一个 Binder 回调）
unregisterUser(IBYDCameraUser):Z
preOpenCamera(IBYDCameraUser):Z
openCamera(IBYDCameraUser):V            打开，数据回调给使用者
posCloseCamera(IBYDCameraUser):Z
getCameraIdByTAG(String, String):I      按 TAG 查机位
isThirdPartyApp(IBYDCameraUser):Z       ⚠️ "第三方 App" 检查
sendCameraAquisitionData(...)           往使用者推数据
getCurrentCameraUser():IBYDCameraUser
```

**数据是通过 Binder 回调推给"使用者进程"的**，不是调用返回值。所以 `service call bydcameramanager 1` 只返回空 Parcel（`00000000 00000000`）—— 服务是通的，但拿不到帧。

要拿帧必须有一个**实现了 `IBYDCameraUser` 接口的进程**去注册。

### 2. 有 `isThirdPartyApp` 白名单检查

即使写了 App，这个方法暗示 BYD **只允许自家/白名单应用**访问相机（大概率是签名或权限校验）。

### 3. root 两扇门都关着

| 尝试 | 结果 |
|---|---|
| `su -c id` / `su 0 id` / `/sbin/su -c id` / `/system/bin/su -c id` | **全部 Permission denied** |
| `/sbin/magisk su -c id` | Permission denied |
| Magisk 版本 | `26001-metagisk:MAGISK:D`（**装了，而且活着**） |
| Magisk 里的 "Shell" 条目 | **灰色不可选** —— Magisk 27+ 默认禁止 shell 提权，UI 不让改 |
| `adb root` | 报 "restarting adbd as root"，但 `id` 仍是 uid 2000（`ro.debuggable=0`，adbd 重启后降权） |

> ⚠️ **注意**：`adb root` 会**破坏 adb 授权状态**。实测执行后车机显示 `offline`、端口通但不弹授权框，客户端重连/重握手全部无效，**必须重启车机才能恢复**。不要随便试。

## 三、唯一看起来可行的突破口（未验证）

只要在车机上以 **root** 执行**一次**：

```sh
chmod 666 /dev/video*
```

之后 adb shell 就能直接读摄像头节点，**剩下的全部可以在电脑这头完成**：
探测每个节点的机位/分辨率/像素格式 → 抓帧 → 传回 → 显示。

**难点在"怎么执行这一条 root 命令"**：

| 办法 | 说明 |
|---|---|
| A | 车机上若有能提权的**终端 App**，敲 `su` + 上面那行 |
| B | 做一个**极小 APK**，申请 root（**Magisk 对 App 是可以授权的，只有 Shell 被禁**），自动跑 chmod |
| C | Magisk 的 SuList / 白名单里加 shell（取决于版本和配置） |

`chmod` **重启失效**，真要用还得做持久化（Magisk 模块 / 开机脚本 / 每次点一下的按钮）。

> 用户实测：App 侧也被 Magisk 挡住了。**这条线暂时搁置。**

## 四、被否决的备选

**记录仪落盘文件**：`/sdcard/DVR/*.mp4`（权限 `root:sdcard_rw`，**shell 能读**）——
是**真实摄像头数据**，但属于"录像文件"而非实时流，**用户明确表示不用这条路**。
